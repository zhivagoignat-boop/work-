# 💪 Жизнь на похудение — личное приложение

Приложение под личный план: **107 кг → 80 кг за 134 дня** (21 сентября 2026 → 1 февраля 2027).
Собрано из мастер-плана [`docs/lifestyle_master_plan.md`](docs/lifestyle_master_plan.md):
тренировки с учётом вывиха плеча, питание без готовки, режим дня — и **постоянный отчёт для Claude**.

## Запуск

### В Telegram (основной способ)

**Приложение опубликовано:** код — в [zhivagoignat-boop/pohudenie-app-](https://github.com/zhivagoignat-boop/pohudenie-app-),
адрес после включения Pages — `https://zhivagoignat-boop.github.io/pohudenie-app-/`.
Этот репозиторий остаётся приватным: здесь план, отчёты и данные.


Приложение работает как **Telegram Mini App**: открывается внутри Telegram, подстраивается
под его тему, синхронизирует данные через облако Telegram и отправляет сводку в чат.

```bash
bash scripts/build-miniapp.sh      # соберёт папку dist/ — только приложение, без личных данных
```

Дальше: выложить `dist` на любой HTTPS-хостинг (проще всего перетащить на
[app.netlify.com/drop](https://app.netlify.com/drop)) и привязать адрес к своему боту
через @BotFather.

📖 **Пошаговая инструкция со скриншотами команд: [`docs/TELEGRAM.md`](docs/TELEGRAM.md)** —
хостинг, создание бота, кнопка меню, ссылка `t.me/бот/app`, обновление и решение проблем.

### Без Telegram — как обычная страница

Сборка не нужна.

```bash
# просто открыть файл
open index.html            # macOS / xdg-open на Linux

# или поднять локальный сервер (нужно для офлайн-режима и установки на телефон)
python3 -m http.server 8000
# затем http://localhost:8000
```

На телефоне: открыть страницу → «Добавить на главный экран». Дальше работает офлайн
(service worker кэширует приложение), данные хранятся в браузере телефона.

## Постоянный отчёт для Claude

Отчёт собирается автоматически из всех отметок и содержит:
вес и отклонение от плановой кривой, прогноз даты достижения 80 кг, дисциплину тренировок,
**отдельный блок по плечу** (пробелы в критичных упражнениях = риск повторного вывиха),
силовую прогрессию, калории и белок, шаги и сон, автоматические флаги проблем,
личные вопросы и машиночитаемый JSON-снимок.

Два способа доставки:

* **Быстрый:** вкладка «Отчёт» → «Скопировать» → вставить в чат.
* **Постоянный:** выгрузить `data.json` в `reports/`, выполнить `node scripts/build-report.mjs`
  и закоммитить — тогда актуальный [`reports/CLAUDE_REPORT.md`](reports/CLAUDE_REPORT.md)
  всегда лежит в репозитории. Подробности — в [`reports/README.md`](reports/README.md).

## Еда по фото

Три пути, от простого к автоматическому:

1. **Через чат** — снимок отправляется Клоду со словом «посчитай», он отвечает
   строками `Блюдо | ккал | белок | жир | углеводы | клетчатка`, строки вставляются
   в приложение и разбираются в список блюд. Ничего настраивать не нужно.
2. **На глаз** — таблица «ладонь = 100 г мяса, кулак = порция гарнира» прямо
   в приложении, когда фотографировать неудобно.
3. **Автоматически** — свой сервис-посредник с ключом Claude API
   ([`worker/`](worker/README.md)), тогда фото считается прямо в приложении.

## Профиль и личные данные

Личные цифры (вес, цель, рост, возраст, даты, имя для вечерних прогулок) **не зашиты в код**:
они задаются на экране первого запуска — вручную или вставкой короткого кода настройки
(`WL1-…`), который можно скопировать на вкладке «Прогресс» → «Профиль» → «Изменить»
и перенести на другое устройство. Благодаря этому код приложения можно публиковать,
не раскрывая ничего личного.

## Данные

Хранятся локально в браузере (`localStorage`, ключ `weightloss.v1`), а внутри Telegram
дополнительно — в облаке Telegram (`CloudStorage`), чтобы подтягиваться на других устройствах.
Никаких своих серверов и аккаунтов. Резервная копия: «Прогресс» → «Экспорт JSON».
Восстановление: «Импорт JSON».

## Перенос тренировок

Не вышло прийти в зал — тренировка переносится на другой день кнопкой «⇄ Перенести».
Если на выбранной дате уже стоит тренировка, они меняются местами. Приложение
предупреждает, когда перенос ставит две тренировки подряд: по плану между ними
нужен день отдыха.

Перенос понимают все части приложения сразу: расписание, меню БодиБалансом
(оно переезжает вместе с тренировкой), блок «Плечо» и отчёт — перенесённый день
не считается пропуском. Сбросить всё обратно можно на вкладке «График».

## Ключевые правила программы (зашиты в приложение)

* Калории 2200–2300 (TDEE 2700 − дефицит 400–500), белок 165–170 г, минимум 120 г.
* Тренировки Пн/Ср/Пт, суббота — опциональное лёгкое восстановление.
* Face Pulls (Пн+Пт), обратный Pec Deck (Пт), гиперэкстензия (Ср) — **никогда не пропускать**.
* Запрещены: жим гантелей вверх, боковые подъёмы, брусья, тяга за голову, отжимания.
* Щелчки или боль в передней части плеча — стоп и к врачу, а не «доработаю подход».
* 10 000 шагов и 8 часов сна ежедневно: TDEE посчитан именно под это.
