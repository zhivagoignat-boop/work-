# 📲 Как запустить приложение в Telegram

Приложение сделано как **Telegram Mini App**: открывается прямо внутри Telegram,
подстраивается под твою тему, синхронизирует данные через облако Telegram
и умеет отправлять сводку в чат.

Нужно два шага: **выложить приложение в интернет** (Telegram открывает только адреса `https://`)
и **привязать его к своему боту**. Всё бесплатно, по времени — 10–15 минут.

---

## Что понадобится

* Telegram на телефоне (и, по желанию, на компьютере).
* Браузер — для BotFather и хостинга.
* Ничего программировать не нужно: приложение уже собрано.

---

# Шаг 1. Выложить приложение в интернет

Выбери **один** вариант. Если сомневаешься — вариант А.

## Вариант А. Публичный репозиторий + GitHub Pages ✅ сделано

Код приложения уже выложен: **https://github.com/zhivagoignat-boop/pohudenie-app-**
Личных цифр в нём нет — профиль задаётся внутри приложения.

Осталось включить раздачу сайта:

1. Открой **https://github.com/zhivagoignat-boop/pohudenie-app-/settings/pages**
2. **Build and deployment → Source: Deploy from a branch**
3. **Branch: main**, папка **/ (root)** → **Save**
4. Через 1–2 минуты приложение будет тут:

   **`https://zhivagoignat-boop.github.io/pohudenie-app-/`**

Этот адрес и нужен для BotFather. Дальше обновления публикуются автоматически при пуше.

## Вариант Б. Без нового репозитория — Netlify Drop (можно прямо сейчас)

В приватном репозитории есть ветка `app-only` — там лежит только приложение,
без отчётов и мастер-плана.

1. Скачай архив:
   **https://github.com/zhivagoignat-boop/work-/archive/refs/heads/app-only.zip**
2. Распакуй — получится папка `work--app-only`.
3. Открой **https://app.netlify.com/drop** и перетащи туда эту папку.
4. Через несколько секунд получишь адрес `https://что-то.netlify.app` — он и нужен.

## Вариант В. Cloudflare Pages

https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** →
**Upload assets** → загрузить ту же папку. Получишь `https://имя.pages.dev`.

## Вариант Г. Только для теста — с компьютера

```bash
python3 -m http.server 8000          # в папке приложения
npx cloudflared tunnel --url http://localhost:8000
```

Временный адрес живёт, пока запущена команда.

# Шаг 2. Создать бота

1. Открой в Telegram **@BotFather** → `/start`.
2. Отправь `/newbot`.
3. Введи название бота, например `Похудение 107→80`.
4. Введи username — латиницей, обязательно заканчивается на `bot`,
   например `pohudenie_107_bot`. Если занят — придумай другой.
5. BotFather пришлёт **токен** вида `8123456789:AAH...`.
   Токен приложению не нужен, но **никому его не показывай** — по нему управляют ботом.

---

# Шаг 3. Привязать приложение к боту

Есть два способа, лучше сделать **оба** — так удобнее открывать.

## 3.1. Кнопка меню в чате с ботом (самый удобный вход)

1. В @BotFather: `/mybots` → выбери своего бота → **Bot Settings** → **Menu Button** →
   **Configure menu button**.
2. Отправь адрес приложения из шага 1 (целиком, вместе с `https://`).
3. Отправь текст кнопки, например `Открыть` или `💪 Похудение`.

Теперь в чате с ботом слева от поля ввода появится кнопка — по ней открывается приложение.

## 3.2. Прямая ссылка вида `t.me/твой_бот/app`

1. В @BotFather отправь `/newapp` → выбери бота.
2. **Title** — название, например `Жизнь на похудение`.
3. **Description** — короткое описание, например
   `Тренировки, питание и отчёт о прогрессе`.
4. **Photo** — картинка **640×360** (можно любой скриншот приложения).
5. **GIF** — отправь `/empty`, анимация не обязательна.
6. **Web App URL** — адрес из шага 1.
7. **Short name** — короткое имя латиницей, например `app`.

Готово: приложение открывается по ссылке `https://t.me/pohudenie_107_bot/app`.
Эту ссылку можно закрепить в «Избранном» — будет как ярлык.

# Шаг 4. Закрепить под рукой

* **Найди своего бота** в поиске Telegram → открой → нажми кнопку меню.
* **Закрепи чат** с ботом вверху списка (свайп по чату → «Закрепить»).
* **На главный экран телефона:** в чате с ботом → «⋮» → «Добавить на главный экран»
  (Android) или поделись ссылкой `t.me/…/app` в Safari → «На экран «Домой»» (iOS).

---

# Шаг 5. Первый запуск: вставить свои цифры

При первом открытии приложение спросит профиль — вес сейчас, цель, рост, возраст, даты
и (необязательно) с кем вечерние прогулки.

Быстрее всего — **вставить код настройки** в поле «Быстро: вставить код» и нажать **OK**:
все поля заполнятся сразу. Свой код я пришлю в чате; он же всегда доступен внутри
приложения: **Прогресс → Профиль → Изменить → код настройки** (кнопка 📋) — им удобно
переносить настройки на второе устройство.

Дальше — обычная работа: отмечаешь упражнения, еду, вес. Ничего больше настраивать не нужно.

# Что появляется именно в Telegram

| Возможность | Как работает |
|---|---|
| **Облачная синхронизация** | Данные сохраняются в облако Telegram. Открыл приложение на другом телефоне или на компьютере — всё на месте. Статус виден на вкладке «Прогресс» → «Синхронизация» |
| **Тема** | Приложение перекрашивается под твою тему Telegram — тёмную или светлую |
| **Нижняя кнопка** | На вкладке «Тренировка» — «Завершить тренировку», на вкладке «Отчёт» — «Скопировать отчёт» |
| **Кнопка «Назад»** | Системная стрелка Telegram возвращает на вкладку «Сегодня» |
| **Вибрация** | Отклик при отметке упражнения и завершении тренировки |
| **«Сводка в чат»** | Вкладка «Отчёт» → короткая выжимка (вес, тренировки, плечо) отправляется в любой чат — удобно закинуть в «Избранное» и оттуда переслать мне |

Полный отчёт для Claude забирается кнопкой **«Скопировать отчёт»** и вставляется в чат со мной.

# Как обновлять приложение

* **Netlify Drop:** пересобрать `bash scripts/build-miniapp.sh` и перетащить `dist` заново
  (в Netlify: сайт → **Deploys** → перетащить папку).
* **Cloudflare Pages:** проект → **Create new deployment** → загрузить `dist`.
* **GitHub Pages:** просто `git push` — workflow опубликует сам.

Telegram кэширует мини-приложения. Если после обновления видишь старую версию:

1. Закрой приложение (крестик) и открой заново.
2. Не помогло — Telegram → **Настройки → Данные и память → Использование памяти → Очистить кэш**.
3. Совсем упрямый кэш — добавь в адрес в BotFather `?v=2` (и меняй цифру при обновлениях).

# Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Белый экран в Telegram | Адрес без `https://`, опечатка или сайт не открывается. Проверь адрес в браузере телефона |
| «Не удалось открыть приложение» | В BotFather указан адрес с `http://` или самоподписанным сертификатом. Нужен настоящий HTTPS (Netlify/Cloudflare/GitHub Pages дают его сразу) |
| Кнопка меню не появилась | Настройка применяется к **чату с ботом**; закрой и открой чат. Убедись, что выбирал именно своего бота в `/mybots` |
| Приложение открывается, но выглядит как обычный сайт (нет синхронизации) | Открыто по прямой ссылке в браузере, а не внутри Telegram. Так тоже можно, но облако и нативные кнопки будут только внутри Telegram |
| На вкладке «Прогресс» написано «локально (обнови Telegram для облака)» | Облако требует Telegram версии 6.9+ — обнови приложение Telegram |
| Данные не подтянулись на втором устройстве | Открой «Прогресс» → «⬇️ Загрузить из облака». На первом устройстве перед этим нажми «☁️ Сохранить в облако» |
| Старая версия после обновления | Кэш Telegram — см. раздел «Как обновлять» выше |
| Не скачивается `.md`/`.json` | Внутри Telegram скачивание файлов часто заблокировано. Пользуйся «Скопировать отчёт» или открой приложение в обычном браузере |

# Приватность

* Приложение статическое: **нет сервера, нет аналитики, никуда ничего не отправляется**.
* Данные лежат в двух местах: в браузере/Telegram на твоём устройстве
  и в **облаке Telegram** (личное хранилище твоего аккаунта для этого бота).
* Хостинг (Netlify/Cloudflare/GitHub Pages) отдаёт только код приложения — твои
  веса, тренировки и отчёты туда не попадают.
* `reports/CLAUDE_REPORT.md` — личные данные. Если будешь делать репозиторий публичным,
  сначала убери их (см. вариант В).
* Токен бота нигде в коде не используется и не нужен приложению.
