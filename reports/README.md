# Постоянный отчёт для Claude

Здесь всегда лежит актуальный срез программы, чтобы Claude мог открыть репозиторий
и сразу видеть, что происходит — без пересказов и скриншотов.

| Файл | Что это |
|---|---|
| `CLAUDE_REPORT.md` | Сам отчёт: вес, тренировки, плечо, силовые, питание, режим, флаги, вопросы |
| `data.json` | Выгрузка приложения, из которой собран отчёт (единственный источник правды) |

## Как обновить (30 секунд)

1. В приложении: вкладка **Отчёт** → **⬇️ Данные .json** (или **Прогресс** → **Экспорт JSON**).
2. Положить скачанный файл сюда как `reports/data.json` (заменить существующий).
3. Выполнить:

   ```bash
   node scripts/build-report.mjs
   ```

4. Закоммитить:

   ```bash
   git add reports/ && git commit -m "report: обновление на $(date +%F)" && git push
   ```

Отчёт можно собрать на другую дату: `REPORT_DATE=2026-11-02 node scripts/build-report.mjs`.

## Как обновить без репозитория

Вкладка **Отчёт** → **📋 Скопировать** → вставить в чат с Claude. Содержимое то же самое.

## Что Claude делает с отчётом

В конце отчёта есть раздел «Что нужно от тебя, Claude» — шесть постоянных вопросов
(темп к цели, первое изменение при плато, пробелы в упражнениях для плеча, прогрессия
весов, добор белка, план на следующую неделю). Свои вопросы добавляются во вкладке
**Отчёт** в поле «Вопросы ко мне» — они попадают в отчёт отдельным разделом.

В конце отчёта есть свёрнутый машиночитаемый JSON-снимок: по нему Claude считает
цифры точно, а не на глаз.
